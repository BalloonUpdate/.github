## 1. 关于我们

- 这里是Minecraft客户端更新助手的的官方组织。我们想要给Minecraft服主们提供一个方便好用的软件给客户端更新模组或者其它文件。  by [MisakaAkio](https://github.com/NiuBoss123) & [Asforest](https://github.com/asforest)

## 2. 项目维护状态

目前主推的大版本是“Mcpatch系列”的2.0版本，其它版本比如JarClient、ExeClient、ClientUpdater、FileSA等版本已经停止维护，请尽量使用新版。

| 仓库                                                         | 用途                 | 状态   |
| ------------------------------------------------------------ | -------------------- | ------ |
| [BalloonUpdate/McPatchDocs](https://github.com/BalloonUpdate/McPatchDocs) | 文档站               | 维护中 |
| [BalloonUpdate/McPatch2](https://github.com/BalloonUpdate/McPatch2) | 管理端源代码         | 维护中 |
| [BalloonUpdate/Mcpatch2JavaClient](https://github.com/BalloonUpdate/Mcpatch2JavaClient) | Java版客户端的源代码 | 维护中 |
| [BalloonUpdate/Mcpatch2RustClient](https://github.com/BalloonUpdate/Mcpatch2RustClient) | Rust版客户端的源代码 | 维护中 |

如果你想要查阅各个系列和大版本的历史过往，可以前往[文档站点](https://balloonupdate.github.io/McPatchDocs/docs)翻阅。
